# Digit Guesser Bot

A Telegram bot for playing a number-guessing game.

## Features
- Interactive number-guessing gameplay
- Message handlers for bot interactions
- Configurable bot settings

## Getting Started

1. Clone the repository:

   git clone https://github.com/iceultanbrynza/digit_guesser_bot.git
   cd digit_guesser_bot


2. Install dependencies:

   pip install -r requirements.txt


3. Configure your bot credentials in config.py.

4. Run the bot:

   python bot.py


## Project Structure

- bot.py — Bot entry point
- config.py — Configuration
- lexicon.py — Bot messages and text
- handlers/ — Message handlers
